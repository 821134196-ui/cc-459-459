# 🎾 网球俱乐部 · 发球机预约与球筐回收系统

管理硬地网球场的**球场 + 发球机双重锁定预约**、电池/球筐领用、训练计时、归还清点、
球数短缺赔偿、电池充电调度、故障维修与经理押金复核。会员与费用均为演示数据，零外部依赖
（Node 22 内置 `node:sqlite` + 原生 HTTP 与前端）。

## 一条命令启动（自动生成冲突 / 雨停 / 短缺样例）

```bash
npm start            # 首次启动自动播种；浏览器打开 http://localhost:3000
npm run reseed       # 清空数据并重新播种演示样例
PORT=3210 npm start  # 自定义端口
npm test             # 40 项测试：双锁 / 续场边界 / 球数差异 / 维修阻断 / 扣款幂等
```

启动即有的演示样例（演示时钟锚定今天 14:00，之后真实流逝）：

| 样例 | 订单 | 说明 |
| --- | --- | --- |
| 进行中 | `LIVE01` | 已领用 BAT-A / BK-01 / 60 球，训练计时中 |
| 待领用 | `NEXT02` | 50 分钟后开场 |
| **迟到释放** | `LATE03` | 已过开场 20 分钟（宽限 15 分钟），首次调度即释放 |
| **球数短缺** | `SHORT4` | 领 60 还 53，短缺 7 颗 → ¥40 扣款待经理复核；BAT-B 充电中 |
| **雨天停场** | `RAIN05` | 按实际训练时长折算费用（¥47），清点无误可直接结单 |
| 已结单 | `DONE06` | 历史单 |
| 维修阻断 | 机器 `PM-103` | 出球口卡球，维修中不可分配 |
| 充电阻断 | 电池 `BAT-B` | 充电未完成（45 分钟），不可分配 |

天气模拟脚本：启动后 **20–80 秒为中雨**，调度器自动给全部球场挂"雨停"旗、雨停后自动摘旗；
前端归还页会出现雨停提示条（位于文档流内，**不遮挡清点结果**）。

## 核心业务规则

- **双重锁定**：预约确认在单个 SQLite 事务内同时检查并锁定球场与发球机。两个订单不能占用
  同一球场**或**同一机器的重叠时段（`[start,end)` 半开区间，首尾相接允许）。
- **领用**：开场领取电池与球筐、记录领出球数；维修中机器、充电未完成/电量 <80% 的电池不可分配。
- **归还清点**：归还设备、球筐与散球；电池立即接入充电（45 分钟由调度器充满置回 `ready`），
  球筐立即回收。清点无误且无待复核扣款才能结单。
- **球数短缺**：2 颗以内为合理损耗；超出部分按 ¥8/颗自动生成扣款**建议**，不直接扣钱。
- **押金扣款**：只允许**经理**依据归还清点记录确认；同一订单同一原因有幂等键，
  重复确认返回原支付流水、绝不重复扣款；经理也可驳回。
- **临时续场**：30/60/90/120 分钟，续场重新检查球场与发球机的后续预约，任一冲突即拒绝。
- **迟到释放**：开场后 15 分钟仍未领用，进程内调度器自动释放双锁。
- **故障维修**：卡球现场可清除；无法清除立即转维修，机器即刻不可分配，修复后恢复。
- **电池掉电**：进行中可更换，旧电池转充电，只能换入已充满的 `ready` 电池。
- **雨天停场**：可按雨停归还，费用按已训练时长折算。

## 界面（硬地视觉：砖红 #9e4a36 / 草绿 #3a6b4f / 白色界线）

- **场地日历**：球场（砖红赛道）与发球机（草绿赛道）叠在同一条 07:00–22:00 时间轴上，
  同一订单在两条赛道同时出现；检测到时间重叠的色块带红色描边，红线为当前时刻。
- **大数字步进器**：归还清点用 76px 大数字 + −/+ 圆形按钮与快捷跳号，下方实时显示
  短缺/一致/多球与拟扣金额。
- **移动端归还页**：窄屏下强制单列（`.return-stack`）。
- **雨停提示**：内联细横幅，可关闭，不使用遮罩/固定定位，不遮挡当前清点结果。

## 技术结构

```
src/
  db.js          SQLite schema（bookings / courts / machines / batteries / baskets /
                 repairs / deductions / incidents / equipment_photos / booking_events…）
  service.js     领域服务：双锁事务、续场、领用/归还、结算、维修、换电、押金幂等、tick 调度
  seed.js        演示数据 + 本地设备照片（SVG 占位图写入 data/photos/）
  scheduler.js   进程内 setInterval：迟到释放 / 充电完成 / 天气挂旗摘旗（默认 5 秒扫描）
  server.js      零依赖 HTTP：JSON API + 静态资源 + 照片读写
public/          原生 HTML/CSS/JS 前端
test/            node:test，40 个用例
data/club.db     SQLite 数据（运行后生成，已 gitignore）
data/photos/     本地设备照片目录
```

### 主要 API

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/state` | 日历/设备/订单/扣款/维修/事件/天气/调度器聚合状态 |
| POST | `/api/bookings` | 新建预约（事务内双锁） |
| POST | `/api/bookings/:id/extend` | 临时续场（重新检查后续预约） |
| POST | `/api/bookings/:id/pickup` | 领用电池+球筐，记录球数 |
| POST | `/api/bookings/:id/return` | 归还清点（`ballsReturned`、`rain`、`scratch`） |
| POST | `/api/bookings/:id/swap-battery` | 电池掉电更换 |
| POST | `/api/bookings/:id/jam` | 卡球登记（无法清除自动转维修） |
| POST | `/api/bookings/:id/settle` | 结单（清点+充电+扣款均完成） |
| POST | `/api/deductions/:id/confirm` | **经理**确认扣款（`role:"manager"`，幂等） |
| POST | `/api/deductions/:id/reject` | 经理驳回 |
| POST | `/api/machines/:id/repair` · `/api/repairs/:id/resolve` | 故障登记 / 修复 |
| POST | `/api/courts/:id/rain` | 球场雨停/恢复 |
| POST | `/api/tick` | 立即执行一次调度扫描 |

模拟适配器：`WeatherAdapter`（按时间轴脚本返回晴/雨）与 `PaymentAdapter`
（内存幂等键，模拟成功/超时），均在 `src/service.js`。
