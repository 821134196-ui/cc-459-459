# 🎾 网球俱乐部发球机预约与球筐回收系统

管理球场、发球机、预约时段、训练模式、电池、球筐编号、网球数量、押金、
领用检查、归还清点与故障维修。零第三方依赖：Python 3.10+ 标准库
（`sqlite3` + `http.server`）+ 原生 HTML/CSS/JS。

## 一条命令启动

```bash
./run.sh              # 重建演示库（含三类样例）并启动 http://127.0.0.1:8000
PORT=9000 ./run.sh    # 自定义端口
```

启动输出包含三组样例：

1. **预约冲突样例** — 1 个成功预约 + 2 个被双重锁定拦截的尝试
   （同球场不同机器 / 同机器不同球场）+ 1 个资源不重叠的并行预约；
2. **雨停样例** — 进行中的训练被突发阵雨挂起（天气适配器返回雨），
   雨停恢复后在场的回到「训练中」，过期未领用的自动释放并退回设备；
3. **球数短缺样例** — 领用 60 颗、归还 54 颗、短缺 6 颗，电池进入
   充电，订单进入「押金复核」队列等经理确认。

另有 **M3 卡球维修中**（预约/领用阻断）和 **BT2 充电中**（还剩约 25 分钟，
未充满不可分配）两个设备阻断样例。

仅重建样例数据不启动服务：`python3 -m app.seed --reset`

## 业务规则

- **双重锁定**：预约确认即同时锁定球场与发球机；两个订单不能在重叠时段
  占用同一球场或同一机器。时段为半开区间 `[start, end)`，首尾相接不冲突。
- **领用检查**：开场前最多 20 分钟领用，同时占用满电电池、空闲球筐、
  发球机，记录发出散球数。维修中的机器、充电未完成的电池不可分配。
- **训练计时**：自领用时计时，页面显示已用时长与计划剩余/超时。
- **临时续场**：按分钟续场，后端重新检查球场与发球机的后续预约，
  碰到任何一个即拒绝。
- **电池掉电**：训练中可换一块满电电池，旧电池立即进入 45 分钟充电，
  同时登记供电故障。
- **归还结单**：必须归还机器、球筐、散球并清点。球筐立即置可用，
  电池进入充电（未充满不可分配），机器恢复可用；卡球则机器转维修。
  清点无误/有短缺都可结单，短缺赔偿挂到押金复核队列。
- **迟到释放**：超过开场宽限（默认 10 分钟）未领用，后台任务自动释放，
  球场与机器的锁同时解除。
- **雨天停场**：挂起当前及 60 分钟内开始的预约与全部球场；雨停后
  未过期的恢复原状态，已过期的自动释放并退回在借设备。
- **故障维修**：卡球/异响等可登记，机器转维修阻断分配；全部未决故障
  修复后才恢复可用。刮伤登记但不阻断使用，赔偿进押金复核。
- **押金复核**：只有经理可依据归还记录确认扣款（球损 ¥8/颗 + 刮伤 +
  其他，不超过押金），模拟支付网关按幂等键退款/扣款；**同一订单只能
  确认一次，重复确认返回原流水，不重复扣款**。

后台进程内调度器每 5 秒巡检一次：迟到释放、电池充满、按天气适配器
自动停场/恢复。

## 页面

| 标签 | 功能 |
| --- | --- |
| 场地日历 | 07:00–23:00 时间轴，**球场泳道（砖红）与发球机泳道（草绿）共用同一横轴**，同一订单上下对齐，含当前时刻线 |
| 预约 | 选会员/时段/球场/机器/模式/押金，冲突时按资源类型醒目提示 |
| 设备可用表 | 机器/电池/球筐/球场状态、充电剩余分钟、未决故障；可切模拟天气 |
| 领用/训练计时 | 领用清单、大数字发球步进器、实时计时、续场、掉电换电 |
| 球筐回收 | **64px 大数字步进器**（±1 / ±5）清点散球，实时显示短缺与赔偿；移动端单列 |
| 故障维修 | 登记故障、修复恢复、历史记录 |
| 押金复核 | 角色切换（前台只能试算/经理才能确认）、试算、幂等确认、流水记录 |

视觉：硬地球场砖红 `#9e3b2e`、草绿 `#3a6f3a`、白色界线；雨停提示为
页面流内横幅（可关闭），不会遮挡正在进行的清点结果。

设备照片保存在本地目录 `data/photos/`，支持 multipart 上传
（`POST /api/photos`），种子数据为内置 SVG 占位图。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

47 个用例覆盖：

- 资源双重锁定（球场/机器重叠、半开区间边界、结单与迟到释放解锁）；
- 续场边界（碰到后续预约的精确边界、机器维度、续后新预约边界）；
- 球数差异（短缺、一致、卡球转维修、刮伤、换电、充电 45 分钟到点）；
- 维修阻断与充电中电池/占用球筐/雨停球场不可分配；
- 押金扣款角色校验与**幂等**（重复确认同流水、不超押金、全额扣款走 capture）；
- 迟到释放、雨停自动挂起/恢复/过期释放、HTTP API 端到端冒烟。
